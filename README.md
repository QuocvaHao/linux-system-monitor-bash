# Linux System Monitor (Bash Script)

## 📌 Giới thiệu
Hệ thống giám sát tài nguyên Linux sử dụng Bash Script.

## ⚙️ Chức năng
- Theo dõi CPU, RAM, Disk
- Dashboard realtime CLI
- Ghi log và CSV
- Phân tích dữ liệu (avg, max, min)
- Vẽ biểu đồ bằng gnuplot
- Tự động bằng cron

## 🚀 Cách chạy
```bash
chmod +x MonitorSystem.sh
./MonitorSystem.sh
